Generates a SHA-256 cryptographic hardware fingerprint combining Motherboard UUID (wmic csproduct), Windows Machine GUID registry keys, CPU ID, and MAC address. Restricts student accounts to authorized campus machines with cryptographic Master Passcode override.

2. Campus Wi-Fi Fencing (ARP BSSID Interrogation)

Interrogates the local system ARP cache table to ensure the client is physically connected to authorized institutional Wi-Fi router BSSIDs, preventing proxy check-ins outside campus.

3. Adaptive Template Learning (Self-Evolving AI)

Automatically adapts to gradual appearance changes (hairstyles, spectacles, beard, natural aging) via Exponential Moving Average blending: E_new = Normalize((1 - 0.12)*E_stored + 0.12*E_cand)

4. Multi-Stage Leave & Automated Archival Daemon

Three-tier workflow (Student → Faculty → Admin). Automated background daemon compresses historical logs at month-end and generates formatted PDF and Excel exports.
